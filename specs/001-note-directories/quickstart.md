# Quickstart: 验证笔记目录（文件夹）管理

## 前置条件

1. 安装依赖：`pnpm install`
2. 生成并应用数据库迁移（新增 `mime_type`、`parent_id` 字段）：

   ```bash
   pnpm drizzle-kit generate
   pnpm db:migrate
   ```

3. 启动本地开发环境：

   ```bash
   pnpm dev
   ```

4. 使用现有登录方式（`/[lang]/signin`）登录一个测试账号，进入 `/en/console/notes`。

## 场景 1：创建根目录下的目录（对应 spec User Story 1 / FR-004~FR-008）

1. 在 `/en/console/notes` 页面，确认"新建笔记"按钮左侧出现"新建目录"入口。
2. 点击"新建目录"，在弹窗中输入名称"工作笔记"，描述留空，点击确认。
3. **预期**：弹窗关闭，列表中出现名为"工作笔记"的目录条目，左侧显示目录图标。
4. 再次点击"新建目录"，输入同样的名称"工作笔记"并确认。
5. **预期**：弹窗内展示"同一目录下已存在同名的目录或笔记"之类的错误提示，未创建重复条目（对应 SC-002）。

## 场景 2：在目录内创建子目录，并校验笔记/目录混合重名（对应 Acceptance Scenario 2 与 4）

1. 点击"工作笔记"目录名称，导航到其子级列表页面（URL 形如 `/en/console/notes?parentId=<base58Id>`）。
2. 点击"新建目录"，输入名称"周报"并确认。
3. **预期**：URL 中的 `parentId` 保持不变，列表中出现"周报"子目录。
4. 返回根目录，创建一个标题为"工作笔记"的普通笔记（沿用 `/en/console/notes/new` 现有流程）。
5. **预期**：由于根目录下已存在同名目录"工作笔记"，创建笔记时应被拒绝并提示名称冲突。

## 场景 3：树形展开/收起与"暂无内容"提示（对应 User Story 2 Acceptance Scenario 1/2/4）

1. 在根目录列表中，找到"工作笔记"目录条目，点击其最左侧三角图标。
2. **预期**：原地展开显示其直接子级"周报"，不发生页面跳转，三角图标变为展开态。
3. 再次点击三角图标。
4. **预期**：子级收起，恢复折叠态。
5. 展开"周报"目录（其内没有任何子级）。
6. **预期**：展开区域显示"暂无内容"提示文案。

## 场景 4：图标与整体缩进（对应 User Story 3）

1. 展开根目录 → "工作笔记" → "周报" 形成三级层级。
2. **预期**：
   - 目录条目与笔记条目左侧图标不同，图标尺寸与文字大小接近。
   - "周报"这一行的三角占位、图标与名称整体相对根层级有两级缩进（而不是仅箭头缩进，图标和文字仍然对齐在根层级）。

## 验证要点对照 Success Criteria

| Success Criteria | 对应验证步骤 |
|---|---|
| SC-001（10 秒内完成目录创建） | 场景 1 步骤 2-3 |
| SC-002（重名 100% 被拦截） | 场景 1 步骤 4-5、场景 2 步骤 4-5 |
| SC-003（原地查看子级无需跳转） | 场景 3 步骤 1-4 |
| SC-004（子级视图状态体现在 URL，刷新仍保留） | 场景 2 步骤 1-3（可额外手动刷新页面验证 `parentId` 仍保留） |
| SC-005（图标 1 秒内区分类型） | 场景 4 |
